# image_processing

Розпізнавання дефектів («висячих» ділянок) на зображеннях круга/квадрата.

**Алгоритм:** зображення → різниця з еталоном → кумулятивна гістограма різниці → одношарова
нейромережа Brain.js (виходи `ok` / `defect`). Обчислення ознак (гістограм) розподілене між
пулом Web Worker'ів (кожне зображення незалежне від інших), саме навчання — в окремому Web Worker.

## Запуск

```
python3 -m http.server 8000     # потім відкрити http://localhost:8000
```

Можна відкрити й `index.html` напряму (`file://`): тоді Web Worker недоступний,
і навчання та обчислення ознак автоматично виконуються в головному потоці.

Бібліотека Brain.js 1.6.1 лежить локально в `lib/` — інтернет не потрібен.

## Файли

| Файл | Призначення |
|---|---|
| `algorithm.js` | ознаки, поділ вибірки, метрики, навчання, `Lab2` для сторінки |
| `worker.js` | Web Worker: навчання поза головним потоком |
| `feature-worker.js` | Web Worker пулу: ознаки (різниця+гістограма) одного зображення, паралельно для кількох |
| `app.js`, `index.html`, `style.css` | інтерфейс |
| `test.js` | перевірка чистих функцій: `node test.js` |
